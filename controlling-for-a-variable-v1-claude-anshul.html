What does it mean to "control for" something?

A plain-language example from an elementary school. No math needed.

Research questionDoes a new reading program improve students' reading scores?

The setup

A school tries a new reading program. Some students join it and some don't. At the end of the year, everyone takes the same reading test.

First look: compare the two groups

Program
78
No program
61

The program group scores 17 points higher. Looks like a big win. But there's a catch.

The catch: who is in each group?

5th grader2nd grader
Program (20 students)
No program (20 students)

The program group is mostly 5th graders. The other group is mostly 2nd graders. Older kids read better anyway, so some of that 17-point gap is really just an age difference, not the program.

Controlling for grade

To control for grade, we hold it constant: compare 2nd graders only to 2nd graders, and 5th graders only to 5th graders.

2nd graders

Program
60
No program
55

5th graders

Program
84
No program
79

Within each grade, program students score 5 points higher. The program still helps, but much less than the first look suggested. The other 12 points were age, not the program.

The takeaway

Controlling for something means comparing like with like, so a difference you don't care about (here, grade) can't sneak into the answer to the question you do care about (does the program work?).

Check yourself: what else might you control for?

Anything that differs between the groups and also affects reading scores. Examples: how well students read at the start of the year, whether English is their first language, or which teacher they have.

Try it yourself: the dataset

These are the 40 students behind the example. Copy the data into a spreadsheet, or download it as a CSV to use in R, SPSS, or Excel. The averages will match the numbers above.

Columns: student_id, grade (2 or 5), program (1 = in program, 0 = not), reading_score.

student_idgradeprogramreading_score

Check: average score by program gives 78 vs 61. Average by program within each grade gives 60 vs 55 and 84 vs 79. A regression of reading_score on program and grade gives a program effect of 5.

Step 2: average score for each combination of program and grade. This is "controlling for grade" done by hand.

tapply(d$reading_score, list(program = d$program, grade = d$grade), mean)

Within each grade, program students (1) score 5 points higher than non-program students (0).
